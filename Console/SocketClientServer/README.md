# Клиент-серверное приложение

Консольное клиент-серверное приложение на C#, демонстрирующее взаимодействие двух приложений посредством TCP-соединения.

Проект состоит из двух отдельных консольных приложений:

* **Client** — клиентская часть;
* **Server** — серверная часть.

## Описание

Клиент устанавливает TCP-соединение с сервером, отправляет данные и получает ответ.

Сервер ожидает входящее подключение, принимает данные от клиента, обрабатывает запрос и отправляет ответ обратно.

В текущей реализации сервер работает в **однопоточном режиме** и обрабатывает подключения последовательно.

### Client

Клиентское приложение отвечает за:

* установление соединения с сервером;
* отправку запросов;
* получение ответов;
* отображение результатов взаимодействия в консоли.

### Server

Серверное приложение отвечает за:

* запуск TCP-прослушивателя;
* ожидание подключения клиента;
* установление соединения;
* получение и обработку запросов;
* отправку ответа клиенту.

## Принцип работы

Общая схема взаимодействия:

```text
┌──────────────┐
│    Client    │
└──────┬───────┘
       │
       │ TCP-соединение
       │
       ▼
┌──────────────┐
│    Server    │
└──────────────┘
```

Клиент инициирует соединение, сервер ожидает входящее подключение.

После установления соединения между приложениями происходит обмен данными.

## Запуск приложения

### 1. Запуск сервера

Сначала необходимо запустить приложение **Server**.

После запуска сервер начинает ожидать подключения клиента.

### 2. Запуск клиента

После запуска сервера необходимо запустить приложение **Client**.

Клиент пытается установить соединение с сервером.

### 3. Взаимодействие

После установления соединения клиент и сервер выполняют обмен данными в соответствии с реализованной логикой приложения.

> Сервер необходимо запустить до запуска клиента.

## Особенности реализации

В текущей версии сервер работает в **однопоточном режиме**.

Это означает, что обработка подключений выполняется последовательно, без параллельной обработки нескольких клиентов.

Такой вариант реализации выбран для демонстрации базового принципа клиент-серверного взаимодействия и работы с TCP-сокетами.
