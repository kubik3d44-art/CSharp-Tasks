# String Compression

Консольное приложение на **C# / .NET**, реализующее алгоритмы компрессии и декомпрессии строк.

Программа позволяет преобразовать последовательности одинаковых символов в компактное представление и восстановить исходную строку из сжатого формата.

---

## Задача

Дана строка, содержащая `n` строчных букв латинского алфавита.

Необходимо реализовать два алгоритма:

- **компрессия** — последовательности одинаковых символов заменяются символом и количеством его повторений;
- **декомпрессия** — сжатая строка преобразуется обратно в исходную.

Если символ встречается в группе только один раз, количество повторений не указывается.

---

## Компрессия

Алгоритм последовательно обрабатывает символы входной строки и подсчитывает количество одинаковых символов, расположенных подряд.

Формат сжатой группы:

```text id="p9zj4w"
<символ><количество>
```

Если количество равно `1`, записывается только символ.

### Пример

Исходная строка:

```text id="r5ykw3"
aaabbcccdde
```

Сжатая строка:

```text id="q0sn8u"
a3b2c3d2e
```

Преобразование можно представить следующим образом:

```text id="i1q6ts"
aaa → a3
bb  → b2
ccc → c3
dd  → d2
e   → e
```

В результате:

```text id="3gyyvd"
aaabbcccdde
     ↓
a3b2c3d2e
```

---

## Декомпрессия

Декомпрессия выполняет обратную операцию.

Алгоритм считывает символ и следующее за ним количество повторений.

Например:

```text id="6kntxb"
a3 → aaa
b2 → bb
c3 → ccc
d2 → dd
e  → e
```

Таким образом:

```text id="ktmxvl"
a3b2c3d2e
     ↓
aaabbcccdde
```

---

## Группы длиной больше 9

Количество повторений может состоять из нескольких цифр.

Например, строка:

```text id="gv59pq"
aaaaaaaaaaaa
```

содержит 12 последовательных символов `a`.

Результат компрессии:

```text id="k84vpq"
a12
```

При декомпрессии число `12` должно восприниматься как единое количество повторений:

```text id="vkaxgj"
a12
 ↓
aaaaaaaaaaaa
```

---

## Алгоритм компрессии

Общий принцип работы:

```text id="owqoqm"
Исходная строка
       │
       ▼
Чтение символа
       │
       ▼
Подсчёт последовательных
одинаковых символов
       │
       ▼
Добавление символа
       │
       ▼
Количество > 1?
    ┌──┴──┐
   Да    Нет
    │      │
    ▼      │
Добавить   │
количество │
    └──┬───┘
       ▼
Следующая группа
       │
       ▼
Сжатая строка
```

При обработке строки достаточно выполнить один последовательный проход по входным данным.

---

## Алгоритм декомпрессии

Общий принцип обратного преобразования:

```text id="cgwvjd"
Сжатая строка
      │
      ▼
Чтение символа
      │
      ▼
Есть цифры после символа?
    ┌─┴───┐
   Да    Нет
    │      │
    ▼      ▼
Считать   Количество
 число       = 1
    │      │
    └──┬───┘
       ▼
Повторить символ
нужное количество раз
       │
       ▼
Исходная строка
```

Если после символа расположено несколько цифр, они обрабатываются как одно число.

---

## Примеры

| Исходная строка | Сжатая строка |
|---|---|
| `aaabbcccdde` | `a3b2c3d2e` |
| `abcde` | `abcde` |
| `aaaaa` | `a5` |
| `aabbcc` | `a2b2c2` |
| `aaaaaaaaaaaa` | `a12` |

После выполнения декомпрессии результат должен совпадать с исходной строкой.

Например:

```text id="3mp4yv"
aaabbcccdde
     │
     ▼
a3b2c3d2e
     │
     ▼
aaabbcccdde
```

---

## Сложность алгоритма

При компрессии каждый символ исходной строки обрабатывается один раз.

Временная сложность:

```text id="uecf5r"
O(n)
```

где `n` — длина исходной строки.

Декомпрессия зависит от размера восстановленной строки и также выполняется последовательным проходом по входным данным.

---

## Тестирование

Для проверки алгоритмов рекомендуется использовать различные варианты входных данных.

Основные сценарии:

- строка с несколькими группами повторяющихся символов;
- строка без повторений;
- строка из одного символа;
- строка, состоящая только из одинаковых символов;
- группы длиной больше 9;
- несколько многозначных групп;
- проверка восстановления исходной строки после компрессии.

Основная проверка корректности:

```text id="9y5zqx"
Decompress(Compress(source)) == source
```

То есть после последовательного выполнения компрессии и декомпрессии должна быть получена исходная строка.

## Результат

В рамках задачи реализованы два взаимосвязанных алгоритма:

- компрессия последовательностей повторяющихся символов;
- восстановление исходной строки из сжатого представления.

Решение демонстрирует работу со строками, последовательную обработку данных и реализацию алгоритма с линейной сложностью.
