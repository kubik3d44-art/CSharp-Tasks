# StringCompression
Реализован алгоритм компрессии строки, содержащей строчные буквы латинского алфавита.

Последовательно идущие одинаковые символы заменяются комбинацией:

<символ><количество>

Если символ встречается в группе только один раз, количество не указывается.

Пример

Исходная строка:

aaabbcccdde

После компрессии:

a3b2c3d2e

Также реализован обратный алгоритм — декомпрессия, восстанавливающий исходную строку из сжатого представления.

a3b2c3d2e
↓
aaabbcccdde

Основная логика

Компрессия выполняется последовательным обходом строки:

определяется текущий символ;

подсчитывается количество его последовательных повторений;

символ добавляется в результат;

если количество повторений больше одного, после символа добавляется число.

При декомпрессии выполняется обратная операция: после символа считывается число повторений, если оно присутствует.

Алгоритм поддерживает группы длиной больше 9, например:

aaaaaaaaaaaa
↓
a12
