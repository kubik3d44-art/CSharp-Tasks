# Потокобезопасный Server 

Описание

Реализован статический класс Server, содержащий общее целочисленное значение count.

Для работы с ним предусмотрены методы:
GetCount()
AddToCount(int value)

К серверу могут одновременно обращаться несколько потоков.

Необходимо обеспечить следующие условия:

  - несколько читателей могут читать значение одновременно;

  - писатели выполняют изменение значения только последовательно;

  - одновременно несколько писателей изменять count не могут;

  - во время записи чтение блокируется до завершения операции записи.

Схема работы

                  Server
                    │
               ┌────┴────┐
               │  count  │
               └────┬────┘
                    │
          ┌─────────┴─────────┐
          │                   │
      GetCount()         AddToCount()
          │                   │
      Читатели             Писатели
          │                   │
          ▼                   ▼
   параллельное          последовательное
      чтение                изменение

Таким образом, решение соответствует классической задаче синхронизации Readers–Writers (читатели–писатели).

Доступ к общему состоянию синхронизирован таким образом, чтобы избежать race condition при конкурентном выполнении потоков.
